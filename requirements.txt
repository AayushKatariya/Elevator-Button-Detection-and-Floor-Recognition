# Elevator Button Detection & Floor Recognition
#
# GPU NOTE (important on Blackwell / RTX 50-series):
#   torch from PyPI ships CUDA 12.4 builds that support up to sm_90. An RTX 5070
#   Ti is sm_120: torch.cuda.is_available() returns True but EVERY kernel launch
#   fails with "no kernel image is available for execution on the device", and
#   Ultralytics will pick the GPU and crash on the first forward pass.
#
#   Install torch from the cu128 index FIRST, then the rest:
#     pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
#     pip install -r requirements.txt
#
#   Verify with a real matmul, not is_available():
#     python -c "import torch; x=torch.rand(512,512,device='cuda'); print((x@x).sum())"
